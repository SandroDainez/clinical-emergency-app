- Onde bula e diretriz divergem, o card mostra **as duas posições rotuladas** ("bula brasileira" × "diretriz AHA/ASA 2026"), nunca só uma.
- Critério de bula **não vira regra determinística**: entra como "critério de bula", informação.
- Nenhuma divergência é resolvida pelo app.
